# 额度预测的口径

额度余量是账号来源报告的当前读数。预测只显示在主窗口，使用同一账号、同一额度窗口最近一次重置或补充以后的百分比读数。它参考 [Magpie 的 quotaEta 计算](https://github.com/yetone/magpie/blob/v0.1.3598/internal/gui/assets/app.js#L16681-L16714)：把最近七天内连续的剩余额度读数拟合成直线，再估算何时降到零。如果预计用完时间晚于下一次重置，则显示按此速度预计能用到重置。这个预测不是官方承诺，也不改变官方剩余百分比。

需要至少三次独立读数，前后覆盖至少一小时。客户端缓存和刷新失败时保留的上一次读数都不作为新样本，也不用来生成预测。缓存没有可核实的读取时间时不标成当前时间。重置或额度回升后重新积累。最近读数超过十五分钟、额度已经用完、当前窗口已经过期，或没有足够样本时，不显示预计用完时间。

预测历史留在本机，保存窗口标识、时间、百分比和重置时间，不包含账号凭据或对话正文。历史文件无法读取时保留原文件，本次有效读数暂存在内存，文件恢复可读后合并。用量同步不会上传这些预测历史。若本机已有 Magpie 的额度历史，只有在当前官方客户端已确认账号邮箱、历史窗口与当前窗口的重置时刻完全一致，且对应关系唯一时，才可用其中本周期的旧读数补足预测；当前余量仍以官方客户端的最新读数为准。

观测台的「周额度下降」对选定时间范围内可确认的周额度消耗分周期累计；重置不会抵消此前的消耗。与 CPA 面板「最近 100% 已用窗口」共用确认消耗区间的规则；不累计平坦尾段、不能确认的区间或截止时间之后的读数。区间边界切到已确认的消耗段时，按段内覆盖时间的比例计算。累计值可超过 100%。默认显示降幅最大的渠道，点击可换渠道。用于同步的是另外保存的、已核实账号的原生额度观测，详见[同步规范](SYNC.md)。
